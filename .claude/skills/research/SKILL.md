---
name: research
description: 对照高可信的一手来源调查问题，并将发现记录为仓库中的 Markdown 文件。当用户要求研究某个主题、收集文档或 API 事实，或把阅读工作委托给后台 agent 时使用。
---

启动一个**后台 agent** 执行研究，让你在它阅读时继续工作。

它的工作：

1. 对照**一手来源**（官方文档、源码、规范、第一方 API）调查问题，而不是阅读对它们的二手转述。把每个声明追溯到拥有该事实的来源。
2. 把发现写入单一 Markdown 文件，并为每个声明引用来源。
3. 将文件保存到仓库已有的同类笔记位置；遵循现有约定。如果没有约定，选择合理位置并说明路径。
